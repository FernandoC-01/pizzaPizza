Sprint 2 - Mom and Pop's Pizzeria

Note: We used a React web front-end, so there is no .exe or .jar file. The file runs with 'npm run dev' as seen below.

How to run the project:
1. Unzip the folder
2. Open the unzipped folder
3. Install Node.js (download from https://nodejs.org) inside folder (with client and README)
4. Navigate to client folder in command prompt/terminal
5. Run: 'npm install' in command prompt (once inside client)
6. Run: 'npm run dev' and click url: http://localhost:5173 to open application
7. If error, install Material UI (if npm install didn't automatically)
