Sprint 2 - Mom and Pop's Pizzeria

Note: We used a React web front-end, so there is no .exe or .jar file. The file runs with 'npm run dev'

How to run the project:
1. Unzip the folder
2. Open the unzipped folder
3. Install Node.js (run: 'sudo apt install nodejs npm' in terminal)
4. Navigate to client folder in terminal
5. Run: 'npm install' in terminal
6. Install Material UI (if npm install didn't automatically)
6. Run: 'npm run dev' and click url: http://localhost:5173
